# Sistema de Notas de Alunos 🎓

Este projeto é uma aplicação prática desenvolvida em **Python** para facilitar o registro e gerenciamento de dados acadêmicos. O sistema opera via terminal, permitindo uma interação direta e rápida para a coleta de informações essenciais de alunos.

## 📋 Sobre o Projeto
O objetivo deste software é organizar o fluxo de entrada de dados escolares. Ele foi estruturado para receber informações cruciais e processá-las em um ambiente de linha de comando (CLI), garantindo que os registros sejam feitos de forma sequencial e clara.

## 🚀 Funcionalidades
O sistema solicita e armazena os seguintes dados:
* **Nome:** Identificação completa do aluno.
* **Idade:** Controle da faixa etária.
* **Série:** Segmentação por ano letivo.
* **Nota:** Registro do desempenho acadêmico.

## 🛠 Tecnologias Utilizadas
* **Linguagem:** [Python 3](https://www.python.org/)
* **Ambiente:** Terminal/CLI
* **Controle de Versão:** Git e GitHub
